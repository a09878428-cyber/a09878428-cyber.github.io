أجهزة الشبكات

تعرف على أهم الأجهزة المستخدمة في بناء الشبكات.

📡

Router

جهاز التوجيه، يربط بين الشبكات المختلفة ويوجه البيانات إلى وجهتها.

🔀

Switch

المحول، يربط أجهزة الشبكة المحلية ويوجه البيانات إلى الجهاز المقصود.

📶

Access Point

نقطة الوصول، تسمح للأجهزة بالاتصال بالشبكة لاسلكياً عبر Wi-Fi.

🖥️

Server

الخادم، يقدم خدمات وموارد لأجهزة أخرى تسمى العملاء Clients.

طرق ربط الأجهزة

Network Topology

تعرف على أشهر أشكال التوصيل الشبكي.

⭐

Star Topology

تتصل جميع الأجهزة بجهاز مركزي مثل Switch أو Hub.

⭕

Ring Topology

تتصل الأجهزة على شكل حلقة، ويرتبط كل جهاز بجهازين آخرين.

🚌

Bus Topology

تتصل الأجهزة بكابل رئيسي واحد يسمى Backbone.

🕸️

Mesh Topology

تتصل الأجهزة بروابط متعددة، مما يوفر مسارات بديلة للبيانات.

عنونة الأجهزة

IP Address و MAC Address

تعرف على العناوين المستخدمة للتعرف على الأجهزة.

🔢

IP Address

عنوان منطقي يستخدم لتحديد الجهاز على الشبكة وتوجيه البيانات إليه.

مثال: 192.168.1.10
🪪

MAC Address

عنوان مادي لواجهة الشبكة، يستخدم للتعرف عليها داخل الشبكة المحلية.

مثال: 00:1A:2B:3C:4D:5E
